# BITRIX-FOR-RASPBERY-PI

## О проекте
Интеграция Bitrix с Raspberry Pi для автоматизации бизнес-процессов и оповещений.

## Технологии
- Bitrix API
- Python 3.10
- Telegram Bot API
- Raspberry Pi
